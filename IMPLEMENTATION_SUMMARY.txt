## Key Implementation Details

1. **No slot check** in handler (slotless by design, per G1)
2. **Strict bool validation** for 'enabled' field (rejects strings, numbers, null, absent)
3. **Two-phase preflight**:
   - Collision check (enable-specific)
   - Retired check (both directions)
4. **Graceful read-back degradation**: responds with requested value if read fails
5. **Immediate SSE publication** with strategy_note to prevent UI staleness
6. **Lock-safe read-back** via apply_unit_file_state under watcher.lock
